# FramedBlocks (Fabric)

**Fabric port of [FramedBlocks](https://github.com/XFactHD/FramedBlocks) for Minecraft 1.20.1.**

FramedBlocks adds a huge collection of decorative framing blocks to Minecraft. Every framing
block accepts a camouflage from any other block, letting you build seamless structures, slopes,
stairs, panels, doors and much more without breaking the visual look of your build.

> **Note:** this is a community port of the original mod by XFactHD, released under the
> [LGPL-3.0 license](./LICENSE). All credits for the design and original code go to
> XFactHD — see [NOTICE](./NOTICE).

---

## Features

- **Camouflage system:** frame any block with any other block and render it seamlessly.
- **120+ block types:** slopes, stairs, panels, posts, doors, trapdoors, collapsible and copycat
  blocks, and more.
- **Double blocks:** place a different camouflage on each half of a block.
- **Ghost rendering, blueprint & toolbox** support for planning large builds.
- Compatible with JEI, REI, EMI, Jade, Create, Athena and Supplementaries.

## Installation

1. Install the [Fabric Loader](https://fabricmc.net/use/) for Minecraft 1.20.1.
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) into the `mods` folder.
3. Drop the FramedBlocks jar into the `mods` folder.
4. Launch the game.

## Building from source

A JDK 17+ is required.

```bash
./gradlew build
```

The built jar is written to `build/libs/`.
